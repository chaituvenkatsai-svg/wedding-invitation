# Krishna & Kartheeka – Wedding Invitation Website

## Run it on your computer (first time)

1. Install Node.js (the "LTS" version) from https://nodejs.org
2. Open a terminal in this folder.
3. Run `npm install` (downloads the tools, takes a minute).
4. Run `npm run dev` and open the address it prints (usually http://localhost:5173).

## Change the wedding details

Edit `src/config/wedding.config.js`. Lines marked `TODO` need your confirmation.
Put photos in `public/images/` and list them in the same file.
